## Architecture decisions

- Before writing code, read the project's accepted ADRs that touch the area you change. Follow them.
- If the project has no ADRs, derive the architecture from the existing code.
- If a change would contradict an accepted ADR, stop and ask the user. The way forward is a new ADR that supersedes it, never silent deviation.
- When an architecture decision is made, record it with the rs-architecture-decision skill.
