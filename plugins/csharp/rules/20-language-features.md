## C# language features

- Use the newest features the project's language version allows, wherever they make the code clearer.
- Pattern matching and switch expressions over chains of `if` and casts.
- Union types over class hierarchies and flag fields for a value that is one of several cases.
- Records for immutable data, with `with` for changed copies.
- Generic math over one overload per numeric type.
- Collection expressions, primary constructors, `required` members and raw string literals where they fit.
- Never use a feature for its own sake. When the older form reads better, keep it.
